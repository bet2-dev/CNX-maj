# CONEXUN – mises à jour de l'appli

Ce dépôt sert uniquement à distribuer les mises à jour de l'appli Android CONEXUN.

- `version.json` : numéro de la dernière version de l'écran et de l'APK.
- `web/index.html` : écran de l'appli, téléchargé automatiquement par les téléphones à l'ouverture.
- `apk/CONEXUN.apk` : dernière APK à installer (quand la partie Android change).

Aucune clé ni mot de passe n'est stocké ici.
